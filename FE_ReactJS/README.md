# Poly Fashion Frontend

Frontend React cho website bán quần áo Poly Fashion.

## Công nghệ

- React, React Router
- Tailwind CSS
- Sonner toast notification
- Axios
- React Slick carousel
- Lucide React icons

## Cài đặt

```bash
npm install
npm start
```

Ứng dụng chạy mặc định tại:

```text
http://localhost:3000
```

## Scripts

```bash
npm start        # chạy môi trường development
npm run build    # build production
```

## Màn hình chính

- Client: trang chủ, cửa hàng, chi tiết sản phẩm, giỏ hàng, thanh toán, đơn hàng, hồ sơ
- Admin: dashboard, sản phẩm, danh mục, đơn hàng, người dùng, bình luận
